Wrapped Tapered Spiral Surfacing Toolpath

This gadget is being developed to create continuous wrapped spiral surfacing toolpaths for tapered rotary work. This version previews sampled wrapped tapered spiral vectors. For this tapered preview phase, use Spiral Pitch mode (axial advance per revolution).
